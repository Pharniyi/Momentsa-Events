# Momentsa Events 🇳🇬

Momentsa Events is a modern, responsive full-stack event discovery and ticketing marketplace designed specifically for the Nigerian scene. From high-energy music festivals and comedy shows in Lagos to tech conferences in Abuja, Momentsa connects event organizers with eager attendees, making ticket booking seamless and secure.

## Key Features

Event Discovery: Filter and search events dynamically by location (states/LGAs), date, category, and budget.

Seamless Booking & Ticketing: Secure, instant checkout with real-time ticket inventory tracking.
Interactive Dashboard:
  Attendees: Manage reservations, view booked tickets, and download QR codes for entry.
  Organizers: Create, update, and track event ticket metrics and analytics.
  Optimized Mobile UX: Lightweight, fast-loading, and mobile-responsive layouts tailored for smooth performance on any network.

## Tech Stack

Frontend: HTML5, CSS3, Next.js TailwindCSS, JavaScript / React
Backend: Node.js
Database: MongoDB
Payment Gateway: Paystack
